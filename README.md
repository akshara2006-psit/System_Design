# 🏗️ System Design & LLD in Java

This repository contains my **System Design and Low-Level Design (LLD)** practice using **Java**.

### 📚 Topics Covered

* OOP & Abstraction
* SOLID Principles
* Design Patterns
* Interfaces & Polymorphism
* Dependency Injection
* Low-Level Design
* Real-World System Design

### 💡 Approach

For each problem, I focus on:

**Requirements → Design → Classes & Interfaces → SOLID Principles → Java Implementation**

The goal is to write code that is **maintainable, extensible, loosely coupled, and easy to understand**.
